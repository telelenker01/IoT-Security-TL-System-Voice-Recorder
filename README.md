# IoT Security TL System - Voice Recorder

## App Description
A professional voice recorder app for continuous 6-hour recording with background support.

## Features
- 6 hours continuous recording
- Background recording
- Silence detection
- Wired microphone support
- Auto file saving
- Offline functionality
